Saludos profesor. En este documento se encuentran las instrucciones para ejecutar el código.


1- Abrir Python con Powershell
2- Dentro de Python escribir la ruta en donde se encuentra el archivo .py y rules.txt. Por ejemplo: "C:\Users\Usuario\Desktop\Actividad 2 Francisco\plan_de_rutas.py"
3- Una vez python haya localizado la carpeta copiar el siguiente comando: "python plan_de_rutas.py rules.txt A E" (Las letras A y E se pueden cambiar para probar diferentes rutas obteniendo a si diversos resultados)

Nota: Tanto el archivo "rules.txt" como el archivo .py deben estar en la misma carpeta.
