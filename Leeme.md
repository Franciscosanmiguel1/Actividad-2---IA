Saludos profesor. En este documento se encuentran las instrucciones para ejecutar el código.


1- Abrir Powershell o CMD

2- Dentro de Powershell o CMD escribir la ruta en donde se encuentra el archivo .py y rules.txt usando el siguiente comando: cd (Acá debe pegar la ruta donde se encuentra el archivo .py)

Ejemplo: cd "C:\Users\profesor\Desktop\Actividad 2 IA\"

3- Una vez haya localizado la carpeta, copiar el siguiente comando: "python plan_de_rutas.py rules.txt A E" (Las letras A y E se pueden cambiar para probar diferentes rutas obteniendo a si diversos resultados)

Nota: Tanto el archivo "rules.txt" como el archivo .py deben estar en la misma carpeta.
